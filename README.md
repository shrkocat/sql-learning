# SQL Learning: From Fundamentals to Advanced Queries

> A personal learning repository by Enrique S. Santeco  
> BS Computer Science — Mapúa University

## Overview

This repository documents my journey in learning **SQL (Structured Query Language)** using **PostgreSQL** as my primary relational database management system (RDBMS).

It serves as a hands-on learning workspace containing SQL scripts, exercises, and practice problems covering fundamental database concepts through more advanced querying techniques.

The goal is to develop a strong foundation in database querying, data manipulation, and data analysis in preparation for real-world data analytics projects.

---

## Learning Objectives

The repository focuses on developing practical SQL skills through:

- Understanding relational databases and SQL fundamentals
- Retrieving and filtering records using SQL queries
- Sorting, grouping, and aggregating datasets
- Joining multiple tables and understanding relationships
- Manipulating and transforming data
- Writing structured and reusable SQL queries
- Applying SQL to practical data analytics scenarios
